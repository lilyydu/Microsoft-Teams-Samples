# Echo Bot - .NET (C#)

This sample demonstrates a simple Echo Bot for Microsoft Teams using .NET and ASP.NET Core.

## Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- A Microsoft 365 account with access to Microsoft Teams
- [DevTunnels](https://learn.microsoft.com/azure/developer/dev-tunnels/overview) for tunneling

## Run the sample

1. Navigate to this directory:
   ```bash
   cd dotnet/EchoBot
   ```

2. Restore dependencies and run:
   ```bash
   dotnet run
   ```

The bot will start listening on `http://localhost:3978`.

Refer to the main [README.md](../../README.md) to interact with your bot in the agentsplayground or in Teams.
